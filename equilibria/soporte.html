Soporte

Equilibria: Redes Flotantes para iPhone y iPad

¿Dudas, un nivel atascado o un fallo? Escríbenos a contacto@barkarum.com con tu modelo de dispositivo y el número de nivel. Respondemos en español.

Cómo se juega

Toca un nodo para repartir: entrega una unidad a cada vecino. Mantenlo pulsado para absorber: toma una de cada vecino. Ganas cuando todos los nodos tienen la misma cantidad.

Cámara y planos

Arrastra el fondo a los lados para girar y arriba o abajo para inclinar. «Aérea» mira desde arriba. En redes de varias capas, toca el número de un plano para aislarlo.

Progreso

Se guarda solo en tu dispositivo. Al borrar la app se pierde.
